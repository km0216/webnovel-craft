# 12 · 人设卡怎么写

> 判据一句话：**这张卡换一本书还能用，它就是废的。**
> 「冷漠、腹黑、外冷内热」谁都能用，读者一个都记不住。人设不是形容词表，是**遇事怎么选**。

## 1. 填空母版（先抄这一份，再往 JSON 落）

填不满不是不会写，是**经历没定**。回去补出生到现在的三件事，再回来填。

## 2. 工序：七步，每步只干一件事

| 步 | 干什么 | 产物 | 常见错 |
|---|---|---|---|
| 1 | 定身份：职业 / 住哪 / 每天几点起 | 三行 | 先想「性格」，结果全是形容词 |
| 2 | 定过去三件事：谁养他、谁伤他、他躲什么 | 三行 | 写成一整篇小传，用不上 |
| 3 | 写表面追求（他嘴上要什么） | 一格 | 写成「想变强」这种没对象的 |
| 4 | 写深层渴望（他不承认要什么） | 一格 | 跟上一格同义 → 重写 |
| 5 | 写把柄：弱点 + 谁知道 + 怎么用 | 两格 | 只写弱点，不写谁会用 |
| 6 | 写行为：三种处境下的第一反应 | 3 条 | 写成形容词（「他很暴躁」） |
| 7 | 写台词：三个场景各一句 | 3 条 | 三句同一个浓度 |

第 7 步放在最后，是因为**台词是前六步的结果**。前六步空着先写台词，写出来的必然是万能句。

## 3. 逐格填法（正例 / 反例 / 判据）

| 格 | 反例 | 正例 | 判据 |
|---|---|---|---|
| 年龄依据 | 18（没别的） | 大一新生，九月满十八 | 能对上职业/学级，后面才不会漂 |
| 表面追求 | 想变强 | 在城里站住脚，攒够下学期学费 | 有对象、有终点、能算钱 |
| 深层渴望 | 其实很善良 | 想有人在门口等她，不是等她干活 | 是需求，不是评价 |
| 怕失去 | 怕失败 | 被送回去 | 具体到一件事 |
| 拿捏 | 他的软肋是家人 | 她妈一句「你爸当年也这样」就让他闭嘴 | 连人带手段 |
| 弱点 | 心软 | 见不得小孩挨饿 | 能单独写成一场戏 |
| 秘密 | 有秘密 | 她妈住院的事没说 | 揭开会改关系，不是谈资 |
| 秘密揭开 | （空） | 他会把她当负担，第二天她就去找第二份工 | 谁变脸、怎么变 |
| 行为 | 性格冲动 | 被问到父母 → 收碗，水开得比平时大 | 触发 + 动作 |
| 锚点 | 很讲义气 | 不解释自己；被逼急了会笑 | 一眼能演出来 |
| 记忆点 | 傲娇毒舌 | 骂完人自己先脸红，然后骂得更凶 | 遮名可辨 |
| 外貌 | 长得很好看 | 肩窄，卫衣能装两个她；右手食指被烟熏黄 | 只写会反复出现的，别写全身像 |
| 功能位 | 女主 | 施压者 | 说清给读者什么 |

## 4. 发动机：表面追求 × 深层渴望

**两格必须错开。** 重合就是一句废话。

| 表面追求（他说的） | 深层渴望（他不承认的） | 错开处 → 生出来的戏 |
|---|---|---|
| 修好那批老照片，攒钱搬走 | 想被人需要一次 | 有人说「你其实不需要谁」，她接下不该接的活 |
| 考上外地大学，离镇子远点 | 想让家里留她 | 家里真放手那天，她自己先反悔 |
| 让所有人怕她 | 想被当大人认真对待 | 有人不怕她、还把她的话当话，她先慌 |

三种错法：
1. 两格同义 → 没有张力
2. 深层渴望写成评价（「其实他心很软」）→ 不是渴望
3. 第一页就点破深层渴望 → 张力提前泄光

## 5. 把柄：弱点要能被用

弱点满足两条才算数，缺一条是装饰：

1. **具体**：「心软」太泛；「见不得小孩挨饿」才能写成一场戏
2. **会被利用**：对手、盟友、甚至她自己知道，就有施压的办法

所以卡上必须写 `leverage`，而且要**连人带手段**：「她妈会用『你爸当年也是这样』这句话让她闭嘴」。
写不出来的，说明这个弱点现在还没人用得上 —— 留着，等有人用得上再写进卡。

## 6. 秘密：写清揭开那天谁变脸

`secret` 可以写「无」，但**有秘密就必须写 `secret_if_revealed`**：

> 如果被揭开，**谁**的态度会变、**怎么**变。

这一格直接决定关系线怎么排。填不出来 = 这个秘密现在没用，先删。

## 7. 说话方式：三处拉开 + 遮名测试

| 维度 | 反例 | 正例 |
|---|---|---|
| 句子 | 说话干脆 | 只说半句，后半句用动作补；越紧张越少话 |
| 口癖 | 语气可爱 | 句尾拖长音；损人时反而变短 |
| 反应速度 | 只写一种语气 | 被抢话时咽回去 / 抢回来 / 干脆不说（`speech.interrupt`） |
| 分对象 | 只写一种语气 | 对长辈客气、对兄弟嘴损、对在意的人先损再软 |

**五场景取样法**：五句台词分别取自——日常废句（几点了 / 冷不冷）· 一句在办事 · 一句答非所问 · 一句被打断的半句 · 一句压不住时。
五句都是「立人设」的漂亮话，说明你写的是标签不是人，哭戏一来就串味。方法细则见 `13-dialogue.md`。

**同声检查**：两张卡的平均句长差 <1.5 字、短句率差 <15% → `char_check.js` 报 `same-voice`。让一个说完整句、一个说碎话，别让两个人共用一种呼吸。

**遮名测试**：把名字和称呼遮掉，念给没看过设定的人听，能不能说出「这是同一个人、什么脾气」。说不出就重写 `lines`。

## 8. 主角写细，配角写准

| | 主角 | 配角 |
|---|---|---|
| 卡片 | 母版全填 | 简版：身份三行 + 记忆点 + 功能位 + 自己的目标 + 3 条行为 + 3 句台词 + 2 条锚点 + 2 组语气 |
| 错误 | 写成完美人设，没有代价 | 只为主角服务，读者不心疼 |
| 关键 | 每卷都要有「他必须选一个」的时刻 | 他要有不依赖主角的欲望 |

配角四件套（缺一件就别出场）：

1. **功能位**：他在故事里给读者什么
2. **记忆点**：遮名也认得出
3. **锚点**：口头禅 / 物件 / 习惯动作，关键时刻回扣
4. **自己的目标**：不靠主角也成立的那个

功能位表：主角 / 施压者 / 看客 / 认可者 / 护短者 / 嘴替 / 搭档 / 镜像对照 / 宿敌 / 牺牲者 / 导师 / 情报源。
**同一卷同一功能位不超过两人** —— 堆三个施压者，读者只记得最烦的那个。
配角高光要站在主角这一边：主角长期被配角压着、关键选择被配角拿走，是弃书的高发点。

## 9. 兑现表：读者在等哪个情绪

读者追的不是「他成长了」，是**情绪的按期兑现**：被承认、被偏爱、被护短、仇人被清算、搭档在紧要关头接住你。

| kind | 什么时候 | 例子 |
|---|---|---|
| 预告 | 前 3 章 | 她冷言甩手，看不上主角 —— 给读者立了字据 |
| 小兑现 | 预告后 1–3 章 | 嘴上还损，但把最后一个位置留给他 |
| 大兑现 | 十几到几十章后 | 当着所有长辈把席位让给他，代价是丢一票 |

三条规则：**成对排**（只预告不兑现 = 吊着；只兑现没预告 = 没人在等）· **强兑现集中写**（连续几章一段弧）· **空窗检查**（一条线多章没动静，要么动它，要么砍它，写进合同）。

## 10. 情欲卡：把性写成节律，不写成清单

成人向书（`book.json` 的 `nsfw.enabled`）里，**有床戏的卡在卡头标 `"nsfw": true`**，卡门才查 `intimacy`；配角不涉性就不标，只出一条提醒。**清单式写法最没用** —— 一串敏感点加几个姿势，写手拿到只能写流程，写不出人。

三格决定一切：

| 格 | 填什么 | 反例 → 正例 |
|---|---|---|
| 主动权 | 谁先动手、动完怎么解释 | 「她很主动」→「她先动手，然后说『是你先看我的』」 |
| 节律 | 分几段、每段谁占上风 | 「吻 → 脱 → 高潮」→「挑衅 → 被按住 → 破防 → 回弹」 |
| 语言衰减 | 台词从什么水平掉到什么水平 | 「她会呻吟」→「整句 → 断句 → 只剩气音 → 事后立刻毒舌」 |

其余四格各一句就够：

- **身体**：成年身体写具体 —— 骨架、会被反复写到的那三处、一处旧痕。别写「身材很好」，写「锁骨深，右侧腰窝比左侧深」
- **不许代称**：卡里出现「那里」「下面」「那个地方」就是没写 —— 卡上先把词写对，正文才会跟着写对（`11-nsfw.md` §2）
- **签名细节至少三处**：写进 `tells` / `body` / `aftercare`，写完一场对着卡打勾一次 —— 写手漏掉的那几拍，往往就是人物崩掉的地方
- **场景骨架**：至少两场，每场写清在哪、谁先动、进到哪一步收（收在动作上，不收在感想上）
- **身体信号**：先说身体，后说感受。「脚趾蜷起来」比「她很兴奋」准十倍
- **死线**：写了死线，越界那一下才有重量；没死线就只是流程
- **事后第一件事**：找衣服 / 背过去 / 去洗 / 说一句难听话 —— 人物在这里最容易崩，也最容易立住
- **第一次**：在哪、谁先、之后关系怎么变；不写「两人发生了关系」这种空话

语域（`voice.lexicon`）决定用词，见 `11-nsfw.md`；**节律和衰减是卡的事，词是语域的事**，混一起就写成成品台词库了。

反例：「敏感点：脖子、腰、大腿。喜欢被亲。」
正例：「被咬耳朵会整条腿绷直，咬着牙不叫出声；叫出声之后就不肯再说话。」

## 11. 十种病，对着改

| 病 | 症状 | 改法 |
|---|---|---|
| 形容词卡 | 全卡找不出一条动作 | 每格改写成「触发 → 反应」 |
| 双胞胎 | 遮名分不清两个角色 | 重写 `speech.by_relation` 与口癖 |
| 万能好人 | 谁都喜欢他，没有代价 | 加 `leverage`，让他为选择付钱 |
| 挂件配角 | 除陪主角没别的事 | 补「自己的目标」，不靠主角成立 |
| 秘密装饰 | 揭开了谁都没变 | 补 `secret_if_revealed`，否则删 |
| 只有设定没有戏 | 背景写得漂亮，进不了场景 | 每题问一句：这格在哪一章能演出来 |
| 全能嘴替 | 每句台词都很妙，像作者在说话 | 砍到只剩他能知道的、他会说的 |
| 崩得快 | 三章内性格变两次 | 崩的前一章找「代价」，没代价不崩 |
| 面板人 | 数值型角色，只会打 | 补怕的东西和拿捏点 |
| 迟到的主角 | 前 5 章都在铺垫别人 | 第一章让他做一次带代价的选择 |

## 12. 卡和流水线怎么接

| 卡里的东西 | 去哪 | 什么时候读 |
|---|---|---|
| 记忆点 / 句法 / 口癖 / 样句 | `rebuild` → `state/context.md` 第 3 栏 | 写每一章都看 |
| 当下状态（位置/目标/关系/物品） | `state` 块 | 每章 `settle` 回写 |
| 兑现表 | `plan/ch/chNNN.contract.json` 的 `must_cover_nodes` / `required_payoffs` | 写前定，写后核 |
| 禁区（不许他知道的） | `forbidden_knowledge` | 编译器硬过滤 |
| 台词 / 行为 / 锚点 | 留在 `canon/characters/<id>.json` | 软审、改稿时对照 |

**只有能进上下文的那几格才算数。** 卡上写得再细，写手看不到等于没写 —— 所以 `stable.speech` 和 `memory_hook` 必须填，它们是唯一进正文路径的部分。

## 13. 反例：一张真实废卡

```
性格：表面毒舌爱挑衅；里子极度怕被讨厌
雷点：被无视、被说小
台词：杂鱼 / 就这 / 刚才不算
```

六处硬伤，逐条对应上文：

1. 表面追求 / 深层渴望没写 → 挑衅没有赌注，等于免费骂街（§4）
2. 「毒舌」是形容词 → 改成「被无视时立刻加话，越加越难听」（§3）
3. 怕丢的两条写了，`leverage` 一条没有 → 没人能拿捏她，冲突只能靠她犯蠢（§5）
4. 秘密空缺 → 关系线只能靠巧合推进（§6）
5. 只有口癖没有分对象 → 遮名测试不过（§7）
6. 五句台词同质 → 写手只能写出一种浓度（§7）

改法不是补几句漂亮话，是**先把五问答完再动笔**。改完的卡：`examples/cards/gan_tang.json`。

## 14. 质检清单

- [ ] 五问全有答案，且都具体到能演
- [ ] 表面追求和深层渴望错开，差在哪写得出来
- [ ] 弱点具体，`leverage` 连人带手段
- [ ] 有秘密就写清谁变脸，没秘密写「无」
- [ ] 行为 3 条以上，全是「触发 → 反应」
- [ ] 台词 3 条以上，遮名可辨，场景不重复
- [ ] `speech.by_relation` 至少两组，语气真的不一样
- [ ] 配角有功能位，同卷同功能位 ≤2
- [ ] 兑现表预告 / 小兑现 / 大兑现齐全
- [ ] （成人向书）`intimacy` 的主动权 / 节律 / 身体信号 / 语言衰减 / 死线 / 事后 都写了
- [ ] 卡里没有一处是「当下状态」（那是 `state` 的事）

机器判（结构，不管好坏）：

```bash
node scripts/new_char.js  --book <书> --id gan_tang --name 甘棠 --role supporting --function 嘴替 --age 18
node scripts/char_check.js --book <书> [--id gan_tang]
```

**它放行不等于卡能写。** 五问答不圆，脚本照样让你过。
