# 05 · 阈值与重标

> 判据要么有倍率，要么能指出触发标记，否则不进引擎。
> 「这段读着有点 AI」不是修改理由；含糊的审美偏好不算数。

## 1. 分级按「改动风险」，不按「特征强度」

| 级 | 含义 | 谁动 |
|---|---|---|
| **A** | 机械可改，改完不损信息 | 脚本给改法，人一键确认 |
| **B** | 建议改，要看上下文 | 人读上下文后改 |
| **C** | 只报数字，不逐句改（结构性指标） | 整篇决策 |
| **H** | 人审区（比喻贴切度等，模型间共识 0–40%），默认保留 | 人 |
| **X** | 已否决——**永不改**，列出来只为防误改 | 谁都不动 |
| **F** | 指纹：方向随模型变，只记密度不做裁决 | 只报 |

**两条方法论纪律**：

1. **分母是同类元素总数**。段级/句级指标用「每百段」「每百句」；用每千字会把标题、列表、表格算进去，量级全错。
2. **改规则前先抽 20 条命中人眼过一遍**，再看频率。宽正则把普通句算成长定语那种事，只看数字发现不了。

## 2. 中文人类的参考线

倍率 = AI ÷ 人类。除注明外，数据来自 `lieflat-less-ai-tone`（中文 520 万字，两轮对照 + 270 对配对复测）与旧包网文统计（七猫 125 本 × 前 8 章旁白、番茄 305 章窗口）。

| 触发器 | 人类参考 | AI | 倍率 | 级 |
|---|---|---|---|---|
| 翻案腔「不是A（而）是B」及其变体 | 0.22/千字 | 0.73 | **3.4×**（配对 δ+0.88 GPT / +0.72 Opus） | A |
| 提示语冒号（「核心是」「关键在于」+冒号，仅「结论提示」子类） | 0.08 | 0.29 | 3.8×（子类 2.1×） | A |
| 起手式（说白了 / 说穿了 / 先说结论 + 逗号） | 0.008 | 0.025 | 3.2× | A |
| 翻译腔：`当…时，` | 0.26 | — | 2.6–5.3×（五种人类样本） | A |
| 翻译腔：`对于…来说 / 就…而言` 话题壳 | 0.22 | — | 同上 | A |
| 翻译腔：段首 `然而，因此，此外，` | 0.18 | — | 同上 | A |
| 过长前置定语（中心词前修饰 >15 字） | ≈0.1 | 0.42 | 4× | A |

## 3. 实测基线（中文都市向长篇 50 章 / 约 15 万字）

| 项 | 实测 | 用法 |
|---|---|---|
| blocking | 0 条 | 硬门设计可用 |
| 微动作密度 | 6.1 / 中位 9.6 / 17.5 每千字 | 阈值必须 >20 才有区分度（旧默认 6 每章必报） |
| 破折号 / 省略号 | **0 次** | 网文正文几乎不用；通用层仍是 F 级，按书 override |
| 套式表情 / 弱化副词 | 0 / 4 次 | 人类≈0，现有阈值（3/千字）方向对，别降 |
| 高频虚词（仿佛/忽然/瞬间） | 0.5/千字 | 阈值 5/千字 合理 |
| 情绪直贴（感到/觉得/心里一暖） | 0.2/千字 | 阈值 2/千字 合理 |

## 4. 阈值怎么重标（换语料/换品类都要走一遍）

1. 取同类样本 ≥10 章（越多越好），跑一遍全量检测
2. 算每条规则的**命中密度分布**，取 p50 当人类中线，p95 当上限
3. 阻断阈值 = p95 以上；advisory 阈值 = p50 × 1.5
4. 写回 `book.json` 的 `thresholds`，并在此文登记「样本 / 日期 / 数值」
5. 跑 `node scripts/fixtures/run_fixtures.js`：人类样本必须 0 blocking

**没有样本怎么办**：标 `confidence: 低`，该条只报不阻断。

## 5. 永不改（X 级）

| 流行说法 | 实测 | 处置 |
|---|---|---|
| 句长太均匀就是 AI（号称 51 倍） | CV 0.58 vs 0.67 = 0.87×；原数字是切句缺陷 | 永不改；把 CV 0.37 拉到 0.67 比不改更糟 |
| 段落均匀 / 凑三个案例 | 三案例占比 0.6% vs 0.5%；差异在案例句**密度** | 永不改 |
| 被动句 / 名词化 / 「其」字 | 4.5% vs 3.2%，人类更多 | 永不改 |
| 「这意味着」式复述 | 反向：人类 0.027 vs AI 0.016 | 永不改 |
| 空转句引列表 / 序数词小标题 | 均反向 | 永不改 |
| 漂亮词黑名单（赋能/闭环/抓手） | δ+0.10 不显著 | 永不改 |
| 首先/其次/总之、设问、明喻、虚词偏少 | 全部 \|δ\|<0.2；虚词方向是**补**不是删 | 永不改 |
| 问句小标题 32 倍 | 分母陷阱，占小标题比例 0.75× | 永不改 |
| 正文问句 / 设问自答 | 人类 17 倍 | 永不改 |
| 句内排比 / 比喻本身 | 句内同字开头人类更多；比喻人类 2.4× | 永不改 |
| 破折号一律删 | 方向随模型反向 | 降为 F，按密度与功能 |
| 短句 = AI 味 | 网文本来就该短 | 永不改；一长一短机械交替才是病 |

**补写禁令**：密度低于人类参考线时，**不因缺失而补写**。补虚词无法验收，补出来是另一种腔。

## 6. 六次翻车记录（改规则前对一遍）

1. 宽正则把普通句算成长定语（3.04 → 修正后 0.35）
2. 规则写「一句内两次」，正则只测了单个连词
3. 正则跨顿号匹配，把正常并列算成嵌套定语
4. 「汉字+冒号」测冒号：6431 命中里 1266 是标题、1225 是列表，全不该改
5. 结构类指标用每千字当分母
6. 写死 11 词比喻表，实际文本里的比喻一个都不在表里

共同点：**都是规则的实现错了，不是数据错了**。所以先抽样验命中，再看数字。
