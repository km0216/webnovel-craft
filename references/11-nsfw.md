# 11 · NSFW 模块

> **默认不加载。** `book.json` 里 `nsfw.enabled: true` 才生效。
> 核心口径：**情欲不许掐灭** —— 不写「他没看」、不切镜头、不含蓄收尾。
> 用词不设死表：**同一个词在古文里是风格，在白文里是回避**。词合不合，看这本书、这场戏、这个人。

## 1. 三样必须落字

每个情欲点都要有：

1. **他看到了什么**（具体部位/具体动作，不是「眼前一片白」）
2. **他的身体反应**（硬/发烫/喉咙干/呼吸重）
3. **她的身体反应**（发软/腿夹紧/打颤/脚趾蜷）

缺任何一样，这一场就是被掐灭的。

## 2. 语域系统（用词「按实际情况」的核心）

词库：`templates/nsfw-lexicon.json`。书目录下放一份 `nsfw-lexicon.json` 可整本覆盖。

**五个域**：

| 域 | 是什么 | 什么时候对 |
|---|---|---|
| `plain` 白描 | 说清在做什么，不绕 | 白文的主叙述默认 |
| `colloquial` 口语 | 日常说法，带语气 | 都市/校园的对白 |
| `crude` 粗口 | 失控、狠话、紧要处 | 强度与情绪一起上来时 |
| `literary` 文雅/古语 | 辞藻本身是卖点 | 古言、古典仙侠 |
| `clinical` 医学 | 准确的解剖表述 | 医患、临床设定 |
| `euphemism` 含蓄 | 靠留白不点破 | 少量调剂；整场都用 = 掐灭 |

**四个 profile**（`book.json.nsfw.profile`）：

| profile | 叙述 | 高潮 | 避开 | 为什么 |
|---|---|---|---|---|
| `white-text` | plain | plain+crude | literary, clinical | 番茄/七猫：文雅读着假，医学读着像诊断书 |
| `literary` | literary+plain | literary+plain | clinical, crude | 古言/仙侠：辞藻是卖点，粗口出戏 |
| `urban` | plain+colloquial | crude+plain | literary, clinical | 都市/校园：口语才像人说话 |
| `clinical` | clinical+plain | clinical+plain | crude, literary | 医患设定：医学词才准确 |

**同一场戏不准混域**。「小穴」和「私处」混着用，读者立刻出戏——这是语域不稳，也是 AI 味的一种。

**对白按人分**：角色卡 `voice.lexicon` 定这个人说哪一档；同一场里她说 `colloquial`，他说 `crude`，是人物区分，不是矛盾。

## 3. 分级与规格

| 级 | 内容 | 最小字数 | 频率 |
|---|---|---|---|
| L1 | 暧昧 | — | 常驻 |
| L2 | 前戏 | 800（擦边点） | 每 2–3 章 |
| L3 | 边缘（非插入） | 800 | 每 2–3 章 |
| L4 | 结合 | 1500（色情场） | 每 6–8 章整场 |
| L5 | 高潮 | 1500 | 同上 |
| L6 | 事后 | 2500（正戏整场） | 同上 |

声明写进 `book.json.nsfw.explicit_level`；本章实际尺度写进合同 `nsfw_level`。**声明和实际不一致时，检查器会指出来。**

## 4. 追踪契约

### 角色性档案（`characters[].intimacy`）

```
orientation     性向
preferences[]   偏好（写具体，不写形容词）
limits[]        本作禁忌（碰了就是错）
first_exp       初情史（什么时候、跟谁、有没有留下痕迹）
voice.lexicon   这个人说哪一档词
voice.silent_when_aroused  上头时是出声还是咬牙
```

### 关系相位（账本里的一条 single 事实）

`S0 陌生 → S1 认识 → S2 在意 → S3 暧昧 → S4 上手 → S5 接吻 → S6 越衣 → S7 结合 → S8 交付`

记成 `A·与B·相位·S5`；变更走 `settle` 的 `supersedes`。**倒退要有人物事件支撑**，否则 `continuity_check` 报 `realm-regress` 同类问题。

### 情欲日志（`ledger/intimacy-log.jsonl`）

一章一行：`{chapter, level, pairs:[[a,b]], new_state, taboos_touched, aftercare}`。
`aftercare` 空着、且本章 level ≥ L4 → 检查器报「没有事后」。

## 5. 检查（`nsfw_check.js`，永不阻断）

```bash
node scripts/nsfw_check.js --book <书> --ch 12          # 只报
node scripts/nsfw_check.js --book <书> --ch 12 --strict  # 有提示就 exit 1（自己要求严的时候）
```

| 规则 | 判什么 |
|---|---|
| `register-mismatch` | 叙述/对白用了本书 profile 不允许的域 |
| `register-mixed` | 同一段混了两端（文雅 + 粗口） |
| `level-exceeded` | 用词强度超过声明的 level |
| `cliche` | 俗套词（好大/好舒服/欲仙欲死/酥麻的电流…） |
| `extinguished` | 声明高尺度却整章含蓄、又没事后痕迹 |
| `no-aftercare` | 声明 L4+ 但找不到事后痕迹 |
| `voice-mismatch` | 对白里出现的域，没有角色设成这一档 |

**为什么不断阻断**：尺度是作者的取舍，不是错误。检查器的职责是把「你自己声明的东西和写出来的东西不一致」指出来，不替人定尺度。

## 6. 俗套黑名单（任何 profile 都该改）

「嗯嗯啊啊」叠字呻吟 · 「不要……不要……停」三段式 · 「好大」「好舒服」直白感叹 · 「你这个磨人的小妖精」· 「欲仙欲死」「攀上顶峰」「融化成一滩水」「酥麻的电流窜过全身」

**替换原则**：抽象词 → 具体部位 + 具体动作 + 具体反应。
不写「电流窜过全身」，写「大腿内侧一直抖，脚趾蜷起来」。

## 7. 和标点、去 AI 味的关系

- 情欲场景**不豁免标点规则**：破折号、省略号按 `05` 的密度判，不因为「在叫」就放过
- 呻吟用**字**不用标点拉长：「疼」比「疼——」好；「叫出来一半，咽回去」比省略号好
- 最像 AI 的四个点：用文雅词代替身体、写到关键处切镜头、五感堆成排比、每段喘一下再停。前两个归本模块，后两个归桶 1 的密度模型

## 8. 常见错法

| 错法 | 症状 | 改法 |
|---|---|---|
| 全篇一个域 | 无论什么场景都是「蜜液」「绞紧」 | 按 profile 分叙述/高潮/对白三档 |
| 用文雅当高级 | 「玉体」「那一处」写法 | 问一句：这是回避还是风格？白文里是回避 |
| 尺度崩 | 声明 L3 写出 L5 的词 | 要么降词，要么改声明（改声明要人拍板） |
| 事后失踪 | 高潮后直接切场 | L6 至少两三句（擦、倒水、说句话、睡过去） |
| 角色同声 | 两个人说一样的脏话 | `voice.lexicon` + 台词样本，一人一道 |
