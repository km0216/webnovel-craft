# 13 · 对白

> 判据三句：**每句在做事**（不是在传信息）· **遮住名字认得出是谁** · **说完之后关系变了一点**。
> 对白不是「让人物说话」，是人物用语言做事 —— 试探、施压、回避、示弱、掩饰、拒绝。说话是表层，动机才是正文。

## 1. 每句在做什么

写之前给这句标个动作。标不出来的，删。

| 动作 | 例句 | 底下在说 |
|---|---|---|
| 试探 | 「你昨晚几点回来的。」 | 我在怀疑你 |
| 施压 | 「我等了一晚上。」 | 我要你道歉 |
| 回避 | 「你吃饭了没有。」 | 别问那个 |
| 示弱 | 「我不知道该怎么办。」 | 你替我拿主意 |
| 攻击 | 「你妈说的吧。」 | 我要贬低你 |
| 反击 | 「你凭什么问我。」 | 我不认你的权力 |
| 示好 | 「顺路。」 | 我特意来的 |

**如果这句唯一的功能是把信息告诉读者，它就是 info dump** —— 改叙述，或者改到下一场再说。

## 2. 潜台词：说 A 指 B

标准做法（海明威《白象似的群山》：一对情人讨论山像不像白象、喝什么酒、车几点到，全篇不提堕胎）：

1. **答非所问**：问「你今晚走吗」，答「外面下雨了」
2. **说反话**：「你走吧。」—— 三个字里全是挽留
3. **只说半句**：「我本来想……算了。」
4. **把话拐到物件上**：谈那杯水、那道菜、那只没关的灯
5. **重复对方的话再改一个字**：「我不是那个意思。」「你是。」

一章里至少有一整场，**谁都没点明真正在说的事**。点明了，读者就没有参与感。

## 3. 四种差异：遮名可辨

| 维度 | 差在哪 | 例 |
|---|---|---|
| 句长 | 有人只说半句，有人能说三句 | 「走。」/「你先别急着走，听我把话说完」 |
| 用词 | 粗词、文词、行话、职业词 | 「行吧」/「可以」/「按流程」 |
| 反应速度 | 抢话 / 慢半拍 / 干脆不答 | 有人接得比谁都快，有人永远慢一句 |
| 口癖 | 少而准，一次一章 | 只说一个词、爱反问、爱叫人全名 |

**遮名测试**：把五句台词的名字和称谓抹掉，念给没看过设定的人听，问「这是同一个人吗、什么脾气」。答不出来就重写。

## 4. 真实语流四件套

初稿最容易犯的错：每句都完整、每句都漂亮、每句都接得上。真人不是这样。

1. **打断**：一句话没说完就被接走（「我把方案——」/「我知道。」）
2. **抢话**：两个人同时开口，一个让了
3. **答非所问**：他问东，她答西，还是答得很自然
4. **重复对方的词**：「你怕我。」「……我不怕。」（重复的是那个怕字）

再加一条：**每场至少一句废句**。问冷不冷、几点了、空调开太低、你这件衣服不错 —— 没有废句，其他台词就没有落差，全成了台词卡。

## 4.5 推挡：赢人的不是漂亮话，是来回

盲测里得分最高的从来不是金句，是**拌嘴**。评语原话：「像两个人在同一间屋里互相推挡。」

**结构**：A 说 → B 顶回去或不接 → A 改口 / 加码。三轮以上才成戏。

| 有没有推挡 | 例 |
|---|---|
| 没有（独白接力） | 「这一条，你写得比在会议室里说的狠。」／「会议室里不方便。」 |
| 有 | 「八点二十。」／「八点。」／「八点二十也没迟到。」 |

**判据**：任意三行台词，能不能看出**谁让步、谁加码**。看不出来，把说话人名字互换也不违和 —— 那就是一人一句独白接力，不是对话。

**改法**：
1. 把机灵句换成笨句（「你自己知道哪个」→「哦。」）
2. 让对方**不接**：沉默、答非所问、只说半个字
3. 让上句被下句**改掉一个字**：「你不怕我。」「我怕过。」

## 4.6 情欲场景的对白俗套

这些句子读者见过一百次，写出来就是「摆拍感」：

| 俗套 | 换成 |
|---|---|
| 「你心跳很快。」 | 一个动作（手指按在腕上、不说话），或一句无关的话 |
| 「别问。」 | 不答，用动作回答 |
| 「疼吗？」 | 留着，但让对方答非所问 |
| 「你怕我。」 | 换成她自己的说法：「你在躲。」 |
| 「叫我的名字。」 | 让她自己叫一次，别下命令 |

判据不变：**能用一个动作替代的台词，就不写台词**。

## 5. 三种形式

| 形式 | 什么时候用 | 例 |
|---|---|---|
| 直接引 | 关键句、张力高的时刻 | 「我不去。」 |
| 转述 | 过场、重复对话、一般交谈 | 他说不去。她问为什么。 |
| 混合 | 大多数场景 | 她问去不去。「我不去。」她没再问。 |

关键句才用引号。整章全是引号 = 没有节奏，也是一眼可见的 AI 味。

## 6. 标记动词：只用「说」

「笑道」「冷冷地反问」「恼火地吼道」都在替对白演戏，读者会注意那个动词而不是话本身。改回「说」，把情绪交给台词和一个动作。

- ✗ 「我不同意。」他愤怒地吼道。
- ✓ 「我不同意。」他说。然后把手从桌上收回去。

## 7. 五个陷阱

| 陷阱 | 症状 | 改法 |
|---|---|---|
| 解释型对白 | 人物替作者交代背景（「你记得吗，三年前……」） | 挪到叙述，或用一句半截话 |
| 过度口语化 | 嗯、啊、那个、就是塞满 | 只留在紧张/说谎那一刻，一次 |
| 副词标记 | 每句都配「冷冷地」「坚定地」 | 删副词，换动作 |
| 人人金句 | 每个人都说得出一句能截图的话 | 全章金句 ≤1 句，其余留笨拙 |
| 独白过长 | 一个人一口气说 60 字以上 | 拆，或让人打断他 |

**人人金句是新手第一大症**：现实里多数人说话笨、重复、逻辑不连。只有少数人该有漂亮话。

## 8. 病历：一场写坏的对白

> 「这一条，你写得比在会议室里说的狠。」
> 「会议室里不方便。」
> 「你刚才不是不动吗。」

三条全中：
1. 第一句是评论家在点评，不是上司在说话 —— 她只会指一行说「这里」
2. 第二句是金句，好听，不像人
3. 第三句是作者借她的嘴抖机灵 —— 她在那种时候不会这么机灵

同段唯一像真人的是「衬衫不脱。」「为什么。」「明天要见人。」—— 因为它具体、日常、有潜台词，而且一点都不聪明。

## 9. 机器：`dialogue_check.js`

```bash
node scripts/dialogue_check.js --book <书> --ch 12
node scripts/dialogue_check.js --file <章节文件> [--strict]
```

| 规则 | 判什么 | 怎么改 |
|---|---|---|
| `dialogue-ratio` | 对白占比 <15% 或 >60%（人类稿 27.7–41.1%，15% 是噪声底不是及格线） | 补对白，或把过场改成转述 |
| `flat-dialogue` | 对白平均 >12 字，且 6 字以内短句不足 35%（人类 5.6–8.4 字 / 52–71%） | 打碎，加半句和打断 |
| `adverb-attribution` | 「笑道 / 冷冷地说」这类标记 | 改回「说」+ 动作 |
| `info-dump-line` | 单句对白 >60 字 | 拆成两句，或让人打断 |
| `no-stumble` | 全章没有一处打断 / 答非所问 / 短接 | 至少加两处 |
| `no-filler-line` | 全章没有一句废句（几点了 / 冷不冷 / 吃没吃） | 加一句，放在紧张前面当垫子 |
| `no-sparring` | 全章短回应顶回去不足两处 | 让人不接、顶回来、改一个字 |
| `cliche-dialogue` | 命中「你心跳很快 / 别问 / 你怕我 / 叫我的名字」这类熟句 | 换成动作，或让她自己的说法 |

脚本判结构，判不了好不好。**放行不等于能看** —— 三判据过不了，脚本照样让你过。

## 11. 盲测：把「像不像人说话」交给不知道内情的人

自己念自己的对白永远听不出假 —— 你知道每句背后想干什么，会自动补语气。所以要盲。

**出包**

```bash
node scripts/blind_test.js --book <书> --ch 12 --out tmp/dlg.txt
```

去掉叙述、去掉「他说/她说」，只留台词，一句一行。两份对照稿分别存成 `_v1.txt` / `_v2.txt`。

**问法**（不要给背景、不要说是自己写的、不要提哪份更好）：
1. realism 1–5：像不像真人会说的话
2. distinct 1–5：能不能感到场上有两个不同的人
3. 各自挑最假的两句、最好的一句

**汇总**

```bash
node scripts/blind_report.js --in tmp/blind.json --markdown
```

输入是 `[{reader, version, realism, distinct}]`，输出均值表 + 判决（差距 <0.5 视为分不开）。**分数是相对分，只能比同一轮的 A/B，跨轮比会骗自己。**

**读结果**

| 结果 | 说明 | 怎么改 |
|---|---|---|
| realism 低、distinct 高 | 台词各有腔调但都太漂亮 | 删金句，补废句和磕碰 |
| realism 高、distinct 低 | 自然，但两个人在说同一种话 | 重写 `speech`，拉句长与用词差 |
| 两份都低 | 场景本身不成立，改情境再写 |
| 两份都高、分不开 | 说明差异没进到字面 —— 好事，别再动 |

**限制**：模型读者不等于人类读者，5 个里 2 个打高分不算数。真人也只找**没看过这份设定**的。分数只用来比较同一批稿的**相对**好坏，不当绝对标准。

**实测一次**（裴知夏第 1 章，3 个盲测者，A/B 标签随机）：

| 版本 | realism | distinct |
|---|---|---|
| 初稿（人人金句） | 2.67 | 2.33 |
| 按本章重写 | 4.00 | 4.00 |
| 第二轮：删一句旁白味台词 + 加一句推挡 | 3.67 | 3.67 |

> 第二轮的绝对分比第一轮低，但**跨轮不能比** —— v2 没改，对手换成了它的改进版，分数自然掉。只读同一轮的 A/B 差：3/3 判改后更好。

被点名最假的是「这一条，你写得比在会议室里说的狠。」「你刚才不是不动吗。」；得分最高的是「八点二十也没迟到。」「说了就行？」—— **赢的是拌嘴，不是漂亮话**。
